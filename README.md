#  반도체 공정 센서 데이터를 활용한 수율 및 불량(Fail) 예측 프로젝트

##  1. 프로젝트 개요
* **데이터셋**: UCI SECOM (실제 반도체 제조 공정에서 수집된 1,567개 웨이퍼의 센서 데이터)
* **목적**: 수백 개의 공정 파라미터 중 불량을 유발하는 핵심 인자를 도출하고, 머신러닝을 통해 불량 웨이퍼를 선제적으로 탐지하는 모델 구축

##  2. 핵심 수행 내용 & 엔지니어적 접근
1. **데이터 전처리 (Data Cleaning)**
   * 41,951개의 결측치 중 신뢰성이 떨어지는 28개의 센서 열을 완전히 제거.
   * 미세 결측치는 공정의 안정성을 가정하여 각 센서의 평균값(Mean)으로 대체하여 데이터 왜곡 최소화.
2. **핵심 공정 인자(KPI) 추출 (Feature Selection)**
   * '차원의 저주'를 해결하기 위해 통계적 기법인 ANOVA(SelectKBest)를 도입, 562개 센서 중 불량과 가장 상관관계가 높은 Top 10 핵심 공정 센서 변수 검거.
3. **클래스 불균형(Class Imbalance) 해결**
   * 초기 수율 분포가 정상 93.36%, 불량 6.64%로 심각하게 편향되어 단일 Decision Tree 모델의 불량 탐지율(Recall)이 10%에 그치는 문제점 발견.
   * **SMOTE(오버샘플링)**를 통해 불량 데이터를 인공 복제하여 50:50 비율로 교정.
4. **앙상블 모델 도입을 통한 성능 업그레이드**
   * 100개의 나무를 결합한 **Random Forest** 알고리즘을 적용하여 양산 관점에서 가장 중요한 지표인 **불량 탐지율(Recall)을 10%에서 38%로 약 3.8배 끌어올리는 성과 달성**.

##  3. 데이터 시각화 및 인사이트
* **상관관계 히트맵(Heatmap)** 분석을 통해 특정 센서군(430, 431, 434, 435번)이 챔버 내부에서 연쇄적으로 얽혀 움직이는 파라미터임을 통계적으로 확인.
* **박막/노광 예측 박스플롯(Box Plot)**을 통해 특정 센서의 산포가 흔들리거나 임계치(Threshold)를 벗어날 때 불량이 집중되는 현상을 시각적으로 증명.
